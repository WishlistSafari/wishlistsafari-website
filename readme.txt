WISHLIST SAFARI WEBSITE: HOW TO PUT IT LIVE

1. Go to app.netlify.com and sign up free with hello@wishlistsafari.com.
2. Choose "Add new site", then "Deploy manually", and drag this whole folder (unzipped) onto the page.
3. In the new site: Site configuration > Forms > Enable form detection, then drag the folder in once more so the two forms are picked up.
4. Forms > Form notifications > add an email notification to hello@wishlistsafari.com for both forms
   (wishlist-enquiry and partner-enquiry).
5. Domain management > Add a domain > www.wishlistsafari.com, then follow Netlify's instructions to update
   the DNS at the company where you registered the domain. HTTPS is switched on automatically.
6. Test: submit one wishlist and one partner enquiry yourself and check both emails arrive.

To change text later: edit the .html files in any text editor and drag the folder in again.
